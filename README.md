# AI-Native Software Engineering Platform

Nền tảng dùng chung hỗ trợ **toàn bộ vòng đời phát triển phần mềm bằng AI** — từ ý tưởng thô / BA / prototype / source code có sẵn đến code đã review. Thiết kế quanh một **senior engineer được khuếch đại**: AI làm phần nặng (BA, research, design, code, test); con người điều phối, quyết định, gác cổng rủi ro.

## Nền tảng ổn định (5 trụ)

```
Capability + Eval + Autonomy + Knowledge + Engineering Lifecycle
```

## Tech stack

- **Backend:** .NET (ASP.NET Core)
- **Frontend:** Vue 3 + TypeScript + Tailwind CSS
